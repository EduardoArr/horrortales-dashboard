# HorrorTales Dashboard

Dashboard interno para la producción de contenido del canal **HorrorTales** (YouTube/podcast en español de true crime, misterio y horror narrado).

## Estructura del proyecto

```
horrortales-dashboard/
├── Api Youtube/    # Integración con la API de YouTube
├── SKILLS/         # Skills de desarrollo (metodología Claude Code)
└── web/            # Aplicación web del dashboard
```

## Qué hace

- Gestiona la producción de guiones y contenido del canal.
- Centraliza herramientas de investigación, escritura y publicación.

## Requisitos

- Node.js
- npm

## Instalación

```bash
git clone https://github.com/EduardoArr/horrortales-dashboard.git
cd horrortales-dashboard
npm install
```

## Uso

```bash
npm run dev
```
